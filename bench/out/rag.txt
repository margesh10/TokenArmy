// payload and reply; `--agent <name>` pins the agent, else it's detected). Shrinks tool results:
//   Bash / PowerShell  noisy command output -> errors, failures, summaries (built-in + learned filters)
//   Grep               long match lists -> grouped by file with counts

//

//

// that keep getting expanded are automatically left alone (see src/learn.js).
//
// Opt out: add `# raw` to a command, TOKENARMY_OFF=1 (everything), TOKENARMY_READ_DEDUPE=0,

### docs/PATTERNS.md:7-20
## 1. The cost model you are actually paying

In an agent loop, turn *n* resends turns 1…n-1. Total input over a session is roughly:

```
Σ (system + tools + memory) · n   +   Σ tool_output_i · (n − i)
```

Two consequences:
- **Fixed preload** (system prompt, tool schemas, CLAUDE.md) is multiplied by turn count. Shrink it once and you save on every turn.
- **Early tool output is the most expensive token you have.** A 5k-token test log on turn 3 of a 40-turn session costs ~185k input tokens. Compressing it at the source (the PostToolUse hook) beats any later summarisation.

Output tokens cost 3-5× more each but are usually only 1-5% of a session's volume. Terse-output skills help cost a little; input discipline helps a lot.

function installDevin({ global = false, cwd = process.cwd(), wrap = false } = {}) {
  const file = devinFile({ global, cwd });
  const cur = readJson(file);
  const ours = devinHooks({ wrap });
  if (global) writeJson(file, { ...(cur || {}), hooks: mergeHooks(cur && cur.hooks, ours) });
  else writeJson(file, mergeHooks(cur, ours));
  const notes = [];
  if (wrap && process.platform === 'win32') notes.push('Wrap mode is skipped on Windows (Devin does not document which shell it uses there); it is active on macOS, Linux and WSL.');
  if (!wrap) notes.push('Devin hooks cannot replace a tool\'s output, so without --wrap TokenArmy adds the project brief, learned facts and the loop guard, but does not shrink command output. Add --wrap to run known-noisy commands through `tokenarmy run`.');
  return { file, notes };
}

### src/learn.js:118-131
function rawLogCommand(file) {
  try {
    const fd = fs.openSync(file, 'r');
    const buf = Buffer.alloc(400);
    const n = fs.readSync(fd, buf, 0, 400, 0);
    fs.closeSync(fd);
    const first = buf.toString('utf8', 0, n).split('\n')[0];
    return first.startsWith('$ ') ? first.slice(2) : null;
  } catch {
    return null;
  }
}
